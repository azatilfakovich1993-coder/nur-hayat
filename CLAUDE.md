# Nur Hayat

Исламское приложение на русском: времена намаза, Коран, обучение арабскому
алфавиту, чат, азкары. React + Vite, Android через Capacitor, веб-версия
одновременно. Около 143 живых пользователей, из них 27 активны за неделю.

Выкладывается в RuStore (Android) и на два адреса в вебе.

---

## Как всё связано

```
                      приложение (Android + веб)
                                 |
                     ВСЁ через nurhayat.ru — прокси на PHP
                    (REG.RU, обычный дешёвый хостинг)
                                 |
        +------------------------+------------------------+
        |                        |                        |
   Supabase                  Nominatim                 Aladhan
 (база, вход,              (поиск города)          (времена намаза)
  чат, файлы)

              видео уроков — МИМО прокси, напрямую:
              nurhayat-videos.s3.twcstorage.ru (Timeweb)
```

Прямой доступ к Supabase, Nominatim и Aladhan из России без VPN ненадёжен —
ради этого и заведён прокси. Его код: `regru-proxy/index.php`, на сервере лежит
в корне сайта. **Локальная копия и файл на сервере должны совпадать** — правь
оба.

Ветки маршрутов в прокси: `/nominatim/`, `/aladhan/`, перенаправление видео,
всё остальное уходит в Supabase.

## Что не доделано

- **Отправить 1.39 в RuStore.** Файл: `nur-hayat-1.39-rustore.apk`. В ней видео
  идут в Timeweb напрямую. Не срочно: у кого стоит 1.38, ролики работают через
  перенаправление в прокси.
- **Перевыпустить ключи хранилища Timeweb** — засветились в переписке. Для
  работы приложения они не нужны, только для заливки новых файлов.
- **Правило перенаправления видео в `index.php` НЕ УДАЛЯТЬ**, пока люди не
  обновятся до 1.39. Оно обслуживает старые версии в два шага: на POST отвечает
  ссылкой само, на GET перенаправляет в Timeweb.
- Настроить в Timeweb предупреждение о низком балансе.

## Сборка и выкладка

```bash
npm run build:android    # ВСЕГДА для Android. Обычный build даёт другой
                         # базовый путь, и приложение зависает на «Загрузка…»
npx cap sync android
cd android && ./gradlew assembleRelease
```

Версию поднимать в `android/app/build.gradle` — и `versionCode`, и `versionName`.

**Веб выкладывается сам** при отправке в ветку `main`: GitHub Actions собирает и
раскладывает на GitHub Pages и Firebase. Переменные окружения для сборки заданы
прямо в `.github/workflows/deploy.yml` — там их два одинаковых набора, менять
надо оба.

## Грабли, на которые уже наступили

**Ключ подписи нельзя ОТКРЫВАТЬ — только копировать.** Файл
`android/nur-hayat-key.jks`, 2716 байт. 17 августа его открыли двойным щелчком,
Блокнот сохранил его как текст, и от файла осталось 2 байта — сборка перестала
подписываться. Спасла копия в Телеграме. Без этого файла обновления в RuStore
выпускать невозможно в принципе: восстановить его неоткуда, только просить
магазин сменить ключ. Проверять целость по размеру: 2716 байт.
Пароль хранилища и ключа один и тот же, лежит в `android/keystore.properties`.

**Видео не должны делить квоту с базой.** 17 августа 2026 обучающие видео
(40 роликов по 14–17 минут, 2 ГБ) съели бесплатные 5 ГБ трафика Supabase, и он
отключил проект целиком: 402 на всё, у всех разом перестал работать вход. Видео
уехали в Timeweb. В Supabase их больше не заливать.

**Постоянные соединения (Realtime) через прокси невозможны.** PHP их держать не
умеет, на каждую попытку отвечает 500. Подписок `postgres_changes` в коде быть
не должно — библиотека при отказе переподключается без остановки, и этот поток
ошибок хостинг принимает за атаку. Чат обновляется опросом.

**Опрос должен быть редким.** Чат когда-то опрашивал сервер три раза в 1,5
секунды — 120 запросов в минуту с телефона. Общий хостинг счёл это атакой и
закрыл доступ мобильному адресу разработчика: приложение «перестало работать на
мобильном интернете», хотя сайт отвечал всем остальным. Сейчас: секунда, пока
идёт разговор, шесть секунд в тишине, ноль в свёрнутом приложении.

**Проверять сеть надо с телефона, а не с компьютера.** На машине разработчика
обычно включён VPN, на телефоне нет. Замеры `curl` с компьютера ничего не
говорят о том, что видят пользователи в России. Правильно: `adb shell ping`,
`adb shell toybox nc -z`, и логи через `adb logcat` с меткой `Capacitor/Console`
(вывод в журнал включается настройкой `loggingBehavior: 'production'` в
`capacitor.config.ts` — временно, перед выкладкой убирать).

**Времена намаза идут через прокси с явной датой.** Без даты Aladhan отвечает
перенаправлением на адрес с датой, и оно уводит запрос мимо ветки `/aladhan/`.

**Даты считать по местному времени, а не UTC.** Из-за этого праздники и
календарь съезжали на день.

## Что надо помнить по срокам

- Сертификат `nurhayat.ru` истекает **8 ноября 2026**. Сторож (edge-функция
  `watchdog`, запускается каждые 5 минут) предупредит за 14, 7 и 1 день —
  push и письмом. После продления обновить дату:
  `{"certExpiresOn":"ГГГГ-ММ-ДД"}` в вызов функции.
- Расчётный период Supabase закрывается **17 числа** каждого месяца.
- Домен требует периодической идентификации владельца через Госуслуги. Не
  пройти в срок — домен отключат, и приложение встанет целиком.
